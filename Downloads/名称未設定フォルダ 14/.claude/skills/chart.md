# Chart Model スキル

## 概要
リアルタイム市場データと蓄積データを組み合わせた定量分析サマリーを表示する。

## データソース

### ローカルデータ（`.claude/data/market/`）
- `timeseries.json` - 日次/週次スナップショット
- `events.json` - イベント・ヘッドラインログ
- `triggers.json` - トリガー水準・監視条件
- `positions.json` - ポジショニングデータ

### リアルタイムデータ（WebSearch）
- 主要指数: SPX, NDX, RUT, VIX
- 商品: WTI, Gold
- 為替・金利: DXY, US10Y, US2Y

## 呼び出しパターン

### `/chart` または `/chart status`
現在の市場状況サマリーを表示:

```
📊 チャートモデル [YYYY-MM-DD HH:MM]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 価格・変動
  SPX: [価格] ([変動%]) | ATH比: [%]
  NDX: [価格] ([変動%]) | ATH比: [%]
  VIX: [値] | カーブ: [contango/backwardation]
  WTI: $[価格] | ホルムズ: [status]

■ CTAトリガー状況
  SPX: [価格] vs [トリガー] → [status]
  NDX: [価格] vs [トリガー] → [status]

■ ガンマ・構造
  SPXディーラーガンマ: [値]bn | [status]
  ポジティブ転換: [レベル] (距離: [%])

■ ポジショニング
  系統的: [percentile]% | 裁量的: [percentile]%
  Vol Control: [percentile]% (5週前: [%])

■ アラート
  [条件1]: [status]
  [条件2]: [status]

■ 次回イベント
  [日付]: [イベント名]
```

### `/chart triggers`
トリガー水準の詳細表示

### `/chart positions`
ポジショニング詳細（CTA/Vol Control/Risk Parity/裁量）

### `/chart events [N]`
直近N件のイベントログ（デフォルト: 5件）

### `/chart compare [date]`
指定日付とのデータ比較

## 実行手順

1. ローカルJSONファイルを読み込み
2. WebSearchでリアルタイムデータ取得（必要時）
3. データをマージしてサマリー生成
4. トリガー・アラート判定
5. フォーマット出力

## データ更新ガイドライン

### 自動更新対象（WebSearch）
- 価格データ（SPX, NDX, VIX, WTI, Gold, DXY, 金利）
- 当日のニュース・ヘッドライン

### 手動更新対象（JSONファイル編集）
- ポジショニングデータ（週次、記事から抽出）
- CTAトリガー水準（記事から抽出）
- ガンマレベル（記事から抽出）

## 関連スキル
- `market-analysis.md` - 記事蓄積・分析フレームワーク

## アラート条件

| 条件 | 閾値 | 現在状態 |
|------|------|----------|
| VIX高止まり | > 25 | 要監視 |
| VIXバックワーデーション | curve = backwardation | 要監視 |
| ブレッドス極端 | SPX 20EMA上 < 10% | 未到達 |
| CTAトリガー抵触 | 価格 < トリガー | SPX/NDX抵触 |

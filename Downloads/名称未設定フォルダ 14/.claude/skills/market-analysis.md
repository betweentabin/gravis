# /market-analysis - HFマーケット記事分析スキル

ヘッジファンドPMやマーケットストラテジストの見解記事を分析し、包括的な投資判断材料を提供します。
**公開データの自動取得機能付き** - 記事内の主張をリアルタイムデータで検証可能。

## 使い方

```
/market-analysis          # 記事分析モード
/market-analysis fetch    # データ取得モード（経済指標・ポジションデータ）
/market-analysis verify   # 記事の主張をデータで検証
```

記事分析：記事本文を貼り付けてください。複数記事を蓄積して統合分析も可能です。

## 統合分析モード

複数記事が蓄積されたら、`/market-analysis summary` で統合分析を実行：

- **コンセンサス**: 複数の著者が一致している見解
- **乖離点**: 著者間で意見が分かれているポイント
- **時系列変化**: 前回から見解がどう変化したか
- **信頼度加重見解**: 著者の過去実績や論理一貫性を考慮した総合判断
- **アクションプラン**: 統合分析に基づく具体的なポジション提案

## データファイル連携

### 構造化データ（`.claude/data/market/`）

記事から抽出した定量データは以下のJSONファイルに蓄積：

| ファイル | 内容 | 更新頻度 |
|---------|------|----------|
| `timeseries.json` | 日次/週次スナップショット（価格、ポジション、ガンマ、ブレッドス） | 記事更新時 |
| `events.json` | イベント・ヘッドラインログ（地政学、データリリース、市場構造） | 随時 |
| `triggers.json` | トリガー水準・監視条件（CTA、ガンマ、VIX、エントリー条件） | 記事更新時 |
| `positions.json` | ポジショニングデータ（系統的/裁量的、フロー、COT） | 週次 |

### 使い方

1. **記事分析時**: 記事から抽出した数値をJSONファイルに追記
2. **検証時**: JSONデータとWebSearch結果を照合
3. **チャートモデル**: `/chart`スキルでリアルタイム統合表示

### 関連スキル

- `/chart` - リアルタイムサマリー表示（データファイル + WebSearch）
